## 🚀 Featured Project

### 🩺 Backend Health & Log Monitor

A Python-based backend monitoring system that automatically checks service health, measures response time, detects application problems, and sends alerts when failures occur.

**Key Features:**

- Automated HTTP health checks
- Response-time and high-latency detection
- Incident detection after consecutive failures
- Automatic recovery detection
- Application ERROR log monitoring
- Persistent log-processing state across restarts
- Configurable monitoring settings
- Discord webhook notifications
- JSONL monitoring history
- Automated unit tests

**Tech:** Python · FastAPI · HTTP/REST · unittest · Discord Webhooks · Git
